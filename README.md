# Full Login, Register, and Password Reset Application

A complete Spring Boot web application implementing user registration, authentication, and password reset functionality with email verification.

## Frameworks Used

### Backend Framework
- **Spring Boot 3.2.5** - Main application framework
- **Java 17** - Programming language

### Security & Authentication
- **Spring Security** - Authentication and authorization
- **BCrypt** - Password hashing algorithm

### Database & Persistence
- **PostgreSQL** - Relational database
- **Spring Data JPA** - Database persistence layer
- **Hibernate** - ORM framework

### Web & UI
- **Spring Web MVC** - Web framework for HTTP requests/responses
- **Thymeleaf** - Server-side template engine
- **Thymeleaf Spring Security Extras** - Security-aware templates

### Email Services
- **Spring Mail** - Email sending functionality
- **JavaMail API** - Email protocol implementation

### Build & Deployment
- **Maven** - Dependency management and build tool
- **Docker** - Containerization (optional)

### Validation
- **Spring Validation** - Form validation and data binding
